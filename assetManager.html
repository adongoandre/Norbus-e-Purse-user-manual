Asset Manager Module Overview

Welcome to Norbus e-Purse Asset Manager Module

A multi-currency, multi-asset class portfolio management module for the management of clients’ investments. All portfolio transactions are handled and managed by the Asset Manager. The Asset Manager module is designed to streamline the management of mutual funds, collective investment schemes, and related operations. It provides a comprehensive suite of tools for fund setup, NAV processing, transaction management, and compliance controls.

This module is essential for financial institutions managing mutual funds, enabling efficient operations, regulatory compliance, and enhanced customer service.
Notable functionalities include:

  • Security setups
  • Setup of benchmarks, brokers, fee setups and computations, issuers and issuer limits, stock markets, etc.
  • Rates update for floating-rated bonds.
  • Update security prices and exchange rates.
  • Capture investment placement.
  • Capture the sale/discount of investments
  • Setup and update of market levies.
  • Setup and computation of dividends and splits.
  • Portfolio management fee computation

Master Setups

Master Configuration

The Asset Manager’s master setup is used for the one-time setup of important features. These master setups show as dropdowns for selection in the customer setup/maintenance pages. Master setups include:

Setup and assignment of portfolio fees as may be determined by the fund management company. There is no limit to the number of fees a company can set up. The fees could be a percentage or a flat amount.

Use the Add New Fee button to create new management fee configurations.

Setup and assignment of portfolio benchmarks to aid in portfolio performance analysis./ Set up and manage performance benchmarks for funds. Define benchmark indices and performance comparison metrics.

Configure benchmark parameters to track fund performance against market indices.

Manage industry sectors for security issuers. Categorize companies and organizations by their business sectors. Every issuer must belong to a sector. This helps the company determine exposure levels.

Create new sectors or modify existing ones using the sector management interface.

Setup of issuers the company transacts business with. Configure and maintain information about security issuers including companies, governments, and other organizations.

Add new issuers or update existing issuer information through the issuer registration form.

Used to set up brokers the company does transactions with. Manage broker information and configurations for trading operations. Set up broker relationships and commission structures.

Register new brokers or modify existing broker details using the broker setup panel.

For setting up stock markets where investments such as stocks are purchased. Configure stock market exchanges and trading venues. Set up market hours, holidays, and trading parameters.

Define market configurations including trading sessions and settlement cycles.

For setting up charges applicable to stock markets. Any number of levies could be set up on a market. The levy could be a percentage or a flat amount. Levies assigned to a market are automatically calculated when the market is selected for a transaction.

Configure levy structures and calculation methods for different market transactions.

Asset Groups

Asset Classification & Management

Manage asset classifications and types for investment portfolios, including asset class definitions and categorization systems.

Configure asset classes such as equities, fixed income, real estate, commodities, and alternative investments. Set up investment parameters and risk profiles for each asset class.

Use the Add New Asset Class button to create additional asset categories and define their characteristics.

Define specific asset class types and sub-categories for more granular investment classification. Create hierarchical structures for detailed portfolio analysis and reporting.

Configure asset type hierarchies and establish relationships between different asset classifications for comprehensive portfolio management.

Securities Management

Securities Configuration Options

The Securities menu button is used for all security-related setups and for security price updates. From the setup of the securities to the update of security prices, and even the coupon rates of floating-rated bonds. Security must be set up in the system before it can be used for a transaction. The characteristics of the security setup determine the behavior of that security when placing a transaction. Securities button has the following submenus:

The industries that the various securities belong to. Every security setup in the system must belong to an industry. Asset Industries allows you to manage and categorize securities by industry sectors. You can create industry classifications, organize securities by market sectors, and maintain structured categorization for better portfolio analysis and reporting.

Clicking on Add Industry allows you to create a new industry category

while clicking on the Edit button allows you to modify existing industry classifications.

New Security Registration allows you to register and configure new securities in the system. You can set up stocks, bonds, mutual funds, and other securities with detailed specifications, pricing information, and associated metadata for comprehensive tracking.

The security setup form allows you to configure all essential details including security type, industry classification, pricing parameters, and trading specifications.

A list of all active securities in the system. Live/Active securities can be edited/deleted here. There is a search form to limit the search to a particular asset class or asset class type for an effective search.

The search interface provides advanced filtering options to quickly locate specific securities based on symbol, name, industry, or other criteria.

Used to view the prices of previously updated securities in the system. It provides a list of security update dates for the user to pick a date to view the prices.

The pricing dashboard displays current market values, price changes, and performance indicators for comprehensive market analysis.

Used to update the coupon rates of floating-rated bonds. For principal repayment bonds, this button is used to indicate the principal paid (if any) on a particular coupon date before the coupon is posted. / Bonds Coupon Schedule allows you to manage and track coupon payment dates for bond investments. You can view upcoming payment schedules, historical coupon payments, and ensure proper income tracking for fixed-income securities in your portfolio.

The coupon schedule interface displays payment dates, amounts, and status for all bond holdings, helping you track income from fixed-income investments.

Corporate Actions

Corporate Action Management

This is used to set up declared dividends. When a dividend is declared for a security, the details, such as dividend year, declaration date, the security the dividend is declared on, the ex-dividend date, dividend per share, and the payment date of the dividend are set here.

Set up and manage dividend declarations for corporate securities, including dividend amounts, record dates, payment dates, and eligibility criteria for shareholders.

Clicking on Declare Dividend allows you to initiate a new dividend declaration process.

The dividend declaration form allows you to specify dividend rates, payment schedules, and shareholder eligibility requirements.

Investment Management

Investment Portfolio Management

Investment Management allows you to handle all aspects of investment operations including booking new investments, managing sales, processing maturities, and tracking active portfolios. You can execute transactions, monitor performance, and manage cash flows for comprehensive investment administration.

Used to capture purchased investments. The security must be set up before the booking is captured. The investment could be purchased or received. To purchase, cash is needed: the settlement amount must be equal to or less than the portfolio’s cash balance. When an investment is received, the cash is not affected.

Clicking on New Investment allows you to book a new investment transaction

while the booking form allows you to enter all necessary investment details including security selection, quantity, pricing, and client allocation information.

Used to capture a sold or discounted investment. An investment could be discounted (where cash is received) or delivered (where cash is not affected). Sell/Deliver Investment allows you to process investment sales and deliveries from client portfolios. You can execute partial or full sales, calculate gains/losses, and manage settlement procedures for investment disposals and transfers.

Clicking on Sell Investment allows you to initiate a sale transaction

while the sale interface allows you to specify quantities, pricing, and settlement terms for the disposal.

For posting matured investment from suspense account to cash or delivering investment in the suspense account where cash is not affected. Post From Suspense allows you to transfer cash from suspense accounts to proper investment accounts. You can allocate unidentified payments, resolve pending transactions, and ensure accurate cash positioning across all investment portfolios.

The suspense management interface displays pending cash items awaiting proper allocation.

Provides a list of currently running investments in the system. The list could be limited to a particular client, issuer, or asset class. The user can also limit the list to a particular security or even a maturity date.

The active investments dashboard provides comprehensive views of all current holdings and their performance metrics.

Used to post(process) matured investments. Matured investments could be posted to cash or suspense. Post Matured Investments allows you to process investment maturities and convert securities to cash. You can handle automatic redemptions, process principal repayments, and manage the settlement of matured fixed-income and other time-bound investments.

Clicking on Process Maturity allows you to convert matured investments to cash

Post Matured Coupons allows you to process coupon payments from bond investments and convert them to cash. You can handle periodic interest payments, manage coupon collection schedules, and ensure accurate income distribution to client accounts.

The coupon processing interface displays all pending coupon payments ready for collection and posting.

Purchase Simulation allows you to model and analyze potential investment purchases before execution. You can calculate costs, fees, yields, and projected returns to help clients make informed investment decisions and optimize portfolio allocations.

Clicking on New Simulation allows you to create a new investment scenario analysis

while the simulation results provide detailed projections and analysis for investment decision-making.

General Transactions

Transaction Management System

General Transactions allows you to manage various financial transactions including general ledger entries, fund transfers, transaction merging, and fee computations. You can process diverse transaction types, handle inter-bank transfers, and manage complex transaction workflows for comprehensive financial operations.

This option is used to capture transactions for adjustment. For example, when there is a bank charge, it must be captured to affect the cash. It can be used to capture transactions that typically happen outside of the application. The user must select a transaction date, a client, the bank account that the transaction will affect, a description for the transaction and the transaction type. The selected transaction type determines the transaction’s effect on cash. For example, interest on call will increase cash while bank charges will reduce the cash.

Clicking on New Transaction allows you to create a new general transaction entry

while the transaction form allows you to specify accounts, amounts, descriptions, and supporting documentation.

Used to move money from one bank account to another. You can move money from one account to another for the same portfolio or from one portfolio to another. If the currencies for the two accounts are different, the exchange rate must be entered for conversion.

Clicking on New Transfer allows you to initiate an inter-bank funds transfer

while the transfer interface allows you to specify beneficiary details, routing information, and transfer amounts.

This is used in two instances:
When a transaction is given to the wrong portfolio, it can be merged and smoothly given to the correct client. The user selects the merge date, the client holding the wrong transaction, and under the transaction list, selects the date range where the wrong transaction(s) were captured. Select the transaction and then select the correct client to merge with that transaction.
Also, if the same client is created twice and both accounts have transactions, the two accounts can be merged. Here, under the transaction list, no transaction is selected (meaning you are merging all transactions).

Clicking on Select Transactions allows you to choose transactions for merging

while the merge process allows you to review, validate, and combine selected transactions into a unified record.

Used to compute management fees for clients. The fee must have been set up (Master Setups) and assigned to the client (Portfolio Update) before the fee could be computed. The fee is calculated for a date range; therefore, the fee range (Date From and Date To) must be selected. Valuation must have been done on those selected dates.

Clicking on Calculate Fees allows you to compute management fees for selected periods

while the fee computation engine applies rate structures, calculates amounts, and generates transaction entries.

Uploads

Bulk Data Upload Management

Uploads allows you to import large volumes of data efficiently through file-based uploads. You can upload investment transactions, sales records, security prices, and exchange rates in bulk, with approval workflows and validation processes to ensure data accuracy and system integrity.

This provides a better option when multiple investments are to be captured. Multiple investments can be prepopulated into a CSV file and uploaded at once. Different types of investments can be uploaded. The upload templates can be downloaded from the General Module.

Clicking on Choose File allows you to select an investment data file for upload

while the validation process checks data integrity and displays any errors or warnings before processing.

Submit Uploaded Investments allows you to review and approve investment uploads before final processing. You can validate uploaded data, make corrections if needed, and submit approved transactions to the main system for official recording and settlement.

Clicking on Review Upload allows you to examine uploaded investments before approval

while the approval workflow ensures all transactions meet compliance requirements before final submission.

Upload Investment Sales allows you to import multiple investment sale transactions from external files. You can process bulk disposals, validate sale details, and prepare sales transactions for approval workflows to efficiently manage large-scale portfolio rebalancing operations. The template can be downloaded from the general module.

Clicking on Upload Sales File allows you to import investment sale transactions

while the system validates sale details including security holdings, quantities, and pricing information.

For submitting investment sale uploads that are pending submission. Submit Uploaded Sales allows you to review and approve investment sales uploads before execution. You can verify sale details, check portfolio positions, and submit approved sales transactions to the trading system for processing and settlement.

The approval dashboard displays all pending sales uploads awaiting review and authorization.

while the review process ensures all sales comply with portfolio guidelines and regulatory requirements.

Security prices can be updated in bulk by making use of this submenu. Uploaded Security Prices allows you to import current market prices for securities from external data sources. You can update portfolio valuations, process daily pricing feeds, and maintain accurate market values for comprehensive portfolio management and reporting.

Clicking on Upload Prices allows you to import security pricing data files

while the pricing engine validates and applies new prices to update portfolio valuations automatically.

For bulk Upload of exchange rates. Uploaded Exchange Rates allows you to import foreign exchange rates from external sources for multi-currency operations. You can update currency conversion rates, process daily FX feeds, and maintain accurate cross-currency valuations for international investment portfolios.

Clicking on Upload Rates allows you to import foreign exchange rate data

while the system validates rates against historical data and applies updates to multi-currency portfolios.

Unsubmitted Items

Pending Submission Management

The unsubmitted items submenu is for submitting records for approval. At the capturing stage, the user has the option to submit the record immediately for approval (by checking the Submit to Checker button) or submit it later. All setups where the Submit To Checker button was not ticked before saving will be pending submission here. The areas include:

Master Setups allows you to review and submit pending master data configurations awaiting approval. You can validate client setups, account configurations, and other foundational data entries before submitting them for authorization and activation in the system.

Clicking on Review Item allows you to examine and validate master setup details

while the submission process allows you to forward completed setups for authorization approval.

Security Setups allows you to review and submit pending security registrations and configurations awaiting approval. You can validate security details, pricing parameters, and classification information before submitting them for authorization and inclusion in the tradeable securities universe.

Review pending security configurations to ensure accuracy before submission for approval.

The validation process checks security specifications and compliance with system requirements.

Corporate Action Setups allows you to review and submit pending corporate action configurations awaiting approval. You can validate dividend declarations, stock split setups, and other corporate events before submitting them for authorization and processing execution.

Examine pending corporate action configurations and validate event details before submission.

Invest Booking/Sales allows you to review and submit pending investment transactions awaiting approval. You can validate investment purchases, sales orders, and transaction details before submitting them for authorization and trade execution processing.

Review pending investment transactions to ensure accuracy and compliance before submission.

The review process validates transaction details, portfolio impacts, and authorization requirements.

General Transactions allows you to review and submit pending general ledger transactions awaiting approval. You can validate transaction entries, account mappings, and supporting documentation before submitting them for authorization and posting to the general ledger.

Portfolio Valuation

Portfolio Valuation & Analysis

Portfolio Valuation allows you to calculate and analyze the current value of investment portfolios. You can perform comprehensive portfolio valuations, generate overview reports, and monitor investment performance to provide accurate asset values and detailed portfolio analytics for decision-making and reporting.

This is where portfolios are valued. It is used to determine the total value of the portfolio’s assets under management on a particular day. Valuation could be done for individuals or all the portfolios under management on a particular day. At the bottom of the valuation page, there is always a summary of the last valuation done (in the case of individual valuation) for comparison with the current valuation.

Clicking on Run Valuation allows you to execute portfolio valuation calculations

while the valuation engine processes all holdings and generates comprehensive valuation reports.

Provides a general overview of the running investments of a portfolio on a particular day. It is like valuing the portfolio, except that this view cannot be saved.

The overview dashboard provides comprehensive portfolio analytics and performance summaries.

Internal Controls

Risk Management & Compliance Controls

Internal Controls allows you to manage risk parameters and compliance limits for investment portfolios. You can set asset allocation limits, configure issuer exposure limits, and define threshold parameters to ensure portfolios remain within acceptable risk boundaries and regulatory requirements.

For viewing and updating asset class allocations. Asset Class Allocations allows you to define and monitor asset allocation limits across different investment categories. You can set minimum and maximum allocation percentages, track current allocations, and receive alerts when portfolios deviate from strategic asset allocation targets.

Clicking on Set Limits allows you to configure asset class allocation parameters

while the monitoring system tracks actual vs. target allocations and generates compliance reports.

For viewing and updating issuer/counterparty limits. Issuer Limits allows you to manage concentration risk by setting exposure limits for individual issuers and counterparties. You can define maximum exposure percentages, monitor current holdings, and prevent excessive concentration in any single issuer to maintain portfolio diversification.

The issuer limits interface allows you to set and monitor concentration limits by issuer.

For updating the minimum or maximum amount thresholds for cash and transfer transactions. Thresholds allows you to define warning and breach levels for various portfolio metrics and risk parameters. You can set threshold values for volatility, duration, credit quality, and other risk measures to receive timely alerts and maintain portfolios within acceptable risk tolerance levels.

Clicking on Set Thresholds allows you to configure warning and breach levels

Reversals

Transaction Reversal Management

Reversals allows you to undo or correct previously processed transactions and operations. You can reverse various types of transactions including valuations, investments, pricing updates, and corporate actions to maintain data integrity and correct processing errors when necessary.


This Functionality helps to reverse every approved Master Setup or Transaction in the asset manager module. You can reverse the approved items under: Portfolio Valuation, Exchange Rates, Security Prices, Investment Booking/Sale, General Transactions, Pay-In-Kind, Posted Dividends, Share Splits, Computed Management Fees, Posted Maturity, Maturity to Suspense.

Reversal Authorization

Reversal Authorization & Approval

Just like the other Modules, this menu is for reviewing and approving or rejecting reversals. Reversal Authorization allows you to review and approve reversal requests before they are executed. You can examine reversal justifications, validate reversal impacts, and provide authorization approval to ensure proper controls and audit trails for all reversal operations in the system.
