Module Overview

Welcome to Norbus e-Purse General Setup Module

The General Setup module is designed to provide a comprehensive overview of the system's configuration and management features. This module allows administrators to set up and manage company-wide settings, user access controls, and system preferences.

The General Setup module is used for company-level configurations and setups that apply to other system modules. Key functionalities include:

  • Enforcement of Maker / Checker Rules
  • LDAPs Configurations
  • Multi-Factor Authentication configurations
  • User Roles and Access Assignments
  • Password Complexity Settings
  • Third-Party Registrations for API authorizations
  • System-wide data templates

Organization Management

Organization Features

Company Settings is where the company is set up.It is the first step in setting up the Norbus e-Purse System. It is where you set up the company name, address, and other company details. It is also where you set up the company logo, which will be used in all reports.

Clicking on edit allows you to add to or make changes to an existing setup, while clicking on the settings button is for setting up controls and automated actions for SMS alerts and enforcing maker checker.

Thus, you can decide :

• Whether the password should have lower case or uppercase
• Whether you want an AM SMS alert with your balance.
• Mutual Fund receipt verification SMS alert.
• PF transfer SMS alert
• Whether the T-bill computation should use interest rate, discount rate or price.
• Whether you want to send new members emails or sms.
• Whether the bond interest is based on the security setup or the average days in a year.

The Norbus System Implements the Maker Checker Policy. The default in the general setup is No. Changing it to Yes means that the inputter or the creator cannot approve.

The Company Access Preference is used to set up system access protocols and password complexity specifications

After which you click on the Update button to save the changes.

The Company Branches is used to set up the branches of the company. It is where you set up the branch name, address, and other branch details.

Clicking on Setup Company Branches allows you to add a new branch

while clicking on the edit button allows you to edit an existing branch.

MFA configurations alllows you to edit Multi-Factor Authentication setups

Clicking on edit allows you make changes to an existing setup

Lightweight Directory Access Protocol (LDAP), It is a protocol used to access and manage directory information services

The LDAP configurations allows you to edit LDAP setups

Clicking on edit allows you to modify existing LDAP settings, such as to enable LDAP, and or to specify LDAP IP or domain. After making changes, click Update to save your configuration.

T24 serves as a centralized platform for managing various banking processes, including account management, transactions, loans, deposits, payments, and more.

The T24 Configurations allows you to enable or disable T24 API Configurations, set a Fund transfer API, API key and Channel ID

The Teller Configurations allows you to edit and Teller setups for cash bank account name and number

General Setup

General Setup Features
System Configuration Options

Currencies allow you to configure and manage currencies used in the system. You can view already populated currencies, add currencies, edit existing currencies or delete irrelevant ones.

Clicking on set up new currency allows you to add a new currency

while clicking on the Edit button allows you to edit an existing currency.

Bank Setup allows you to view existing banks or set up new banks. You edit and delete the existing setups or add more banks by clicking on ‘setup new bank’ and inputting the required details:

Bank Name, BIC (swift code), and Code(branch identifier)

Clicking on set up new bank allows you to add a new bank

while clicking on the Edit button allows you to edit an existing bank.

The bank code is a descriptive name that helps you to identify the account. You should be able to identify it as soon as you see it. The bank code is what appears on the statement.

Clicking on set up new bank code allows you to add a new bank code

while clicking on the Edit button allows you to edit an existing bank code.

Payment Modes allows you to view all existing payment modes

Pending Events allows you to view and manage events such as, maturing coupons and investments, that are scheduled but not yet completed. Maturing coupons can be edited to provide a prompt on a number of days before coupons to mature.

Clicking on edit allows you edit the number of days before you recieve a prompt on coupon maturity.

Access Management

User Access Control

Access roles allow you to define user roles and permissions for different system functions. You can create a role by granting or denying access to certain functionalities. What you grant access to is what the user can see when they log in. The type of accessible report to a particular role can also be viewed. You can create new roles, edit existing roles, and assign permissions to each role.

Clicking on create role allows you to create a new access role and specify permissions for that role

while clicking on the Edit button allows you to edit an existing access role and its' permissions.

Clicking on the View button allows you to view the permissions granted to a particular role from each module.

Clicking on the Report Access button allows you to view the reports accessible to a particular role.

This section is used for setting up new users, as well as viewing and updating details of existing users. Administrators can add new user accounts, assign roles, and manage user information to ensure proper access control within the system. The search bar also allows you to search for a user by name or email.

Clicking on set up new user account allows you to add a new user account

while clicking on the Edit button allows you to edit an existing user account.

The status section of the table shows you currently active users. The delete button is to remove a user account from the system, and the De-activate button allows you to de-activate a user from using the system, while the reset button allows you to reset a user's password.

Login activities allow you to monitor user login activities and access patterns. You can view login history, track user access, and identify any suspicious activities. You first filter the login activities by User by fetching the user's full name from the dropdown.

Clicking on the fetch button allows you to view the login activities of a particular user.

Security Best Practice: Regularly review user access rights and remove unused accounts.

SMS Setups & Automation

SMS Configuration Options

SMS setups allow you to configure SMS settings for notifications, alerts, and automated messages. You can set up SMS providers, manage templates, and automate SMS sending for various events.

SMS Provider allows you to set up and manage your SMS provider settings. You can configure the provider's API, manage account details, and ensure proper integration with system.

Clicking on add provider allows you to add a new SMS provider

while clicking on the Edit button allows you to edit an existing SMS provider.

SMS Balance allows you to check your SMS active provider, SMS rate, account balance and total SMS. You can monitor usage, ensure sufficient balance for sending messages, and manage costs effectively.

SMS Templates allow you to create and manage SMS templates for various notifications and alerts. You can customize messages, set placeholders, and automate SMS sending based on specific events.

Clicking on new template allows you to add a new SMS template

while clicking on the Edit button allows you to edit an existing SMS template.

SMS Automation allows you to set up automated SMS sending based on specific triggers or events. You can define rules, conditions, and actions to ensure timely notifications and alerts.

Clicking on add automation allows you to add a new SMS automation Schedule

Troubleshooting, Support & Resources

Common Issues & Solutions

Problem: Unable to login to the system
Solutions:
  • Verify username and password are correct
  • Check if account is locked or expired
  • Ensure browser cookies and JavaScript are enabled
  • Contact system administrator for password reset

Problem: "Access Denied" when trying to access certain features
Solutions:
  • Check your user role permissions
  • Verify you have the required access level
  • Request additional permissions from administrator
  • Log out and log back in to refresh permissions

Problem: System running slowly or timing out
Solutions:
  • Clear browser cache and cookies
  • Check network connectivity
  • Close unnecessary browser tabs
  • Try accessing during off-peak hours

Problem: Data not loading or showing incorrectly
Solutions:
  • Refresh the page (F5 or Ctrl+R)
  • Check date range filters
  • Verify data permissions
  • Contact administrator if data appears corrupted
Important: If issues persist, document the error message and steps taken before contacting support.
