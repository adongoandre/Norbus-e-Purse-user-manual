Cashier Module Overview

Welcome to Norbus e-Purse Cashier Module

The Cashier module serves as the primary transaction processing hub for all financial operations across the system. It handles receipts, withdrawals, contributions, and redemptions with comprehensive workflow management and real-time notifications.

The Cashier Module provides complete functionality for:

  • CIS receipt capture and verification
  • Redemption request processing
  • Asset manager transaction handling
  • Provident fund contribution management
  • Withdrawal and termination processing
  • Bulk upload and batch processing
  • Real-time workflow notifications

Getting Started with Cashier Operations
1 Transaction Capture: Create new transactions using the appropriate capture forms for each operation type.
2 Submission Process: Submit captured transactions for review and approval through the workflow system.
3 Verification & Approval: Review and verify submitted transactions before final processing.
4 Communication: Send confirmations and receipts to members and stakeholders.
Best Practice: Monitor live notifications regularly to ensure timely processing of all transactions.

CIS Receipts

Collective Investment Scheme Receipt Processing

Comprehensive receipt management for collective investment schemes including individual captures, bulk uploads, verification workflows, and member communications.

  • Capture Receipt: Create new individual member receipts with payment details
  • Submit Receipt: Submit captured receipts for verification and processing

  • Upload Receipts: Bulk upload multiple receipts using CSV/Excel templates
  • Submit Uploads: Submit bulk uploaded receipts for batch processing

  • Verify Receipts: Review and verify submitted receipts for accuracy
  • Undo Verified Receipt: Reverse verification if corrections are needed
  • Email Receipts: Send receipt confirmations to members

CIS Redemptions

Collective Investment Scheme Redemption Management

Process member redemption requests for collective investment schemes including individual applications and bulk upload capabilities with comprehensive approval workflows.

  • Redemption Request: Create new redemption applications for members
  • Submit Redemption: Submit redemption requests for approval and processing

  • Upload Redemption Requests: Bulk upload multiple redemption applications
  • Submit Redemption Requests: Submit bulk redemptions for batch approval

Asset Manager Receipts

Asset Management Receipt Processing

Handle asset manager receipts including individual captures, bulk processing, verification workflows, and member communication for asset management transactions.

  • Capture Receipt: Create new asset manager receipts with investment details
  • Submit Receipt: Submit captured receipts for verification process

  • Upload Receipts: Bulk upload asset manager receipts using templates
  • Submit Uploads: Submit bulk uploaded receipts for processing

  • Verify Receipts: Review and verify submitted asset manager receipts
  • Undo Verified Receipt: Reverse verification for corrections
  • Email Receipts: Send receipt confirmations to stakeholders

Asset Manager Withdrawals

Asset Manager Withdrawal Processing

Process withdrawal requests for asset management clients including individual applications and comprehensive approval workflows to ensure proper authorization.

  • Capture Withdrawal: Create new withdrawal applications for clients
  • Submit Withdrawal: Submit withdrawal requests for approval

  • Approve Withdrawals: Review and approve submitted withdrawal requests

Provident Fund Contributions

Provident Fund Contribution Management

Comprehensive contribution processing for provident fund members including individual captures, bulk uploads, verification workflows, and member communications.

  • Capture Contributions: Record individual member contributions and employer matches
  • Submit Contributions: Submit captured contributions for verification

  • Upload Contributions: Bulk upload member contributions using payroll files
  • Submit Uploads: Submit bulk contribution uploads for processing

  • Verify Contributions: Review and verify submitted member contributions
  • Undo Verified Contributions: Reverse verification for corrections
  • Email Contribution Receipts: Send contribution confirmations to members

Provident Fund Withdrawals

Provident Fund Withdrawal & Termination Processing

Process member withdrawal and termination requests for provident fund schemes including individual applications, bulk processing, and comprehensive approval workflows.

  • Withdrawal Requests: Create withdrawal and termination applications for members
  • Submit Withdrawal Requests: Submit requests for approval and processing

  • Upload Withdrawal Requests: Bulk upload multiple withdrawal applications
  • Confirm Withdrawal Requests Uploads: Submit bulk withdrawals for approval
