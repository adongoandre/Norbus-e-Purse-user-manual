Teller Overview

Welcome to Norbus e-Purse Teller Operations Module

The Teller Operations module provides comprehensive cash handling capabilities for front-office banking operations. This module handles all aspects of customer cash transactions, from deposits and withdrawals to balance inquiries and transaction monitoring.

The Teller module provides complete functionality for:

  • Cash deposit processing and receipt generation
  • Cash withdrawal authorization and disbursement
  • Real-time balance inquiry and account verification
  • Transaction history tracking and monitoring
  • Daily cash management and reconciliation
  • Comprehensive audit trails and reporting
  • Integration with T24 core banking system

1 Login & Setup: Access your teller workstation and verify cash drawer balance.

Cash Deposits

Cash Deposit Processing

Capture Deposit allows tellers to process customer cash deposits efficiently with proper verification and receipt generation.

Deposit Process Features:
  • Account Verification: Validate customer account number and details
  • Amount Entry: Enter deposit amount with currency validation
  • Fund Selection: Choose appropriate fund type for the deposit
  • Reference Generation: Automatic Norbus reference number creation
  • T24 Integration: Real-time posting to core banking system
  • Receipt Printing: Generate customer deposit receipt
Tip: Always count cash twice and verify the amount with the customer before processing.

Completed Deposits provides a comprehensive view of all successfully processed deposit transactions with detailed status information.

Completed Deposits View:
  • Transaction Details: Account name, number, amount, and fund type
  • Reference Numbers: Both Norbus and T24 reference tracking
  • Status Monitoring: Real-time transaction status updates
  • Search & Filter: Find specific transactions quickly
  • Export Options: Generate reports in various formats
Note: All completed deposits are automatically included in daily reconciliation reports.

Deposit Status Categories:
  • Pending: Deposits awaiting T24 confirmation
  • Completed: Successfully processed and posted deposits
  • Reversed: Deposits that have been reversed or cancelled
  • Failed: Deposits that encountered processing errors
Important: Monitor pending transactions regularly and escalate any prolonged delays.

Cash Withdrawals

Cash Withdrawal Processing

Capture Withdrawal enables tellers to process customer cash withdrawals with proper authorization and security checks.

Withdrawal Process Features:
  • Account Validation: Verify customer account and available balance
  • Identity Verification: Confirm customer identity before processing
  • Limit Checking: Validate withdrawal against daily/transaction limits
  • Authorization: Secure authorization process for large withdrawals
  • Cash Disbursement: Controlled cash dispensing with proper documentation
  • Receipt Generation: Provide withdrawal receipt to customer
Security: Always verify customer identity using acceptable identification documents.

Withdrawal History provides comprehensive tracking of all withdrawal transactions processed through the teller system.

History Management:
  • Transaction Log: Complete record of all withdrawal transactions
  • Status Tracking: Monitor transaction status from initiation to completion
  • Reference Management: Track both internal and T24 reference numbers
  • Audit Trail: Detailed audit information for compliance
  • Search Capabilities: Quick search by account, amount, or date range
Data Retention: Withdrawal history is maintained for regulatory compliance periods.

Withdrawal Authorization Matrix:
  • Standard Withdrawals: Teller authorization up to daily limit
  • High Value: Supervisor approval required for large amounts
  • Manager Override: Branch manager authorization for exceptional cases
  • System Limits: Automated enforcement of transaction limits
Best Practice: Escalate unusual withdrawal patterns to supervisors immediately.

Balance Inquiry

Account Balance and Details Verification

Check Balance provides real-time access to customer account information and available balances across different fund types.

Balance Inquiry Features:
  • Real-time Data: Live balance information from T24 core system
  • Account Details: Complete customer and account information display
  • Multiple Funds: View balances across different fund categories
  • Available Balance: Display available vs. current balance
  • Account Status: Check account status and any restrictions
  • Mini Statement: Option to print recent transaction summary
Real-time: Balance information is updated in real-time from the core banking system.

Account Verification ensures proper customer identification and account validation before processing any transactions or providing account information.

Verification Process:
  • Account Number: Validate account number format and existence
  • Customer Details: Verify customer name and personal information
  • Account Status: Check for any account blocks or restrictions
  • Signature Verification: Compare customer signature when required
  • ID Verification: Validate acceptable identification documents
Security: Never provide account information without proper customer verification.

Transaction History

Comprehensive Transaction Tracking and Monitoring

All Transactions View provides a comprehensive dashboard showing all teller transactions across different categories with real-time status updates.

Transaction Overview Features:
  • Unified Dashboard: Single view of deposits, withdrawals, and inquiries
  • Status Categories: Completed, pending, reversed, and failed transactions
  • Real-time Updates: Live transaction status from T24 integration
  • Transaction Counts: Summary statistics for performance tracking
  • Amount Totals: Financial totals for reconciliation purposes
  • Export Capabilities: Generate reports for audit and compliance

Transaction Analytics provides detailed analysis and reporting capabilities for teller performance monitoring and operational insights.

Analytics Features:
  • Performance Metrics: Transaction volume and processing time analysis
  • Trend Analysis: Historical transaction patterns and trends
  • Error Rates: Monitoring of failed and reversed transactions
  • Peak Hours: Identification of busy periods for resource planning
  • Customer Patterns: Analysis of customer transaction behaviors
Insight: Use analytics to optimize teller operations and customer service.

Audit Trail maintains comprehensive records of all teller activities for compliance, security, and operational review purposes.

Audit Capabilities:
  • Complete History: Full transaction lifecycle tracking
  • User Actions: Record of all user interactions and modifications
  • System Events: Automated logging of system-generated events
  • Timestamp Accuracy: Precise timing of all activities
  • Search Functions: Advanced search and filtering capabilities
  • Compliance Reports: Pre-formatted reports for regulatory requirements
Compliance: Audit trails are tamper-proof and maintained for regulatory periods.

Reports & Analytics

Comprehensive Reporting and Business Intelligence

Daily Reconciliation provides end-of-day reporting and cash management tools to ensure accurate financial controls and proper cash handling.

Reconciliation Features:
  • Cash Position: Beginning balance, transactions, and ending balance
  • Transaction Summary: Count and totals by transaction type
  • Variance Analysis: Identification of discrepancies and over/short amounts
  • T24 Reconciliation: Matching with core banking system records
  • Exception Reports: Highlighting unusual transactions or patterns
  • Approval Workflow: Supervisor review and sign-off process
Important: Daily reconciliation must be completed before end-of-business operations.

Performance Reports provide detailed analysis of teller productivity, efficiency metrics, and operational performance indicators.

Performance Metrics:
  • Transaction Volume: Number of transactions processed per period
  • Processing Time: Average time per transaction type
  • Error Rates: Frequency of corrections and reversals
  • Customer Wait Time: Service delivery efficiency metrics
  • Peak Period Analysis: Workload distribution throughout the day
  • Comparative Analysis: Performance benchmarking against targets

Compliance Reports generate regulatory reports and ensure adherence to banking regulations and internal policies.

Compliance Features:
  • Regulatory Reports: Pre-formatted reports for regulatory submission
  • Large Transaction Reports: Monitoring of high-value transactions
  • Suspicious Activity: Flagging of unusual transaction patterns
  • Policy Adherence: Monitoring compliance with internal procedures
  • Document Retention: Proper archiving of transaction records
Regulatory: All compliance reports are automatically archived for required retention periods.

Key Operational Guidelines:

  • Complete daily reconciliation before end of business
  • Report any system issues or discrepancies immediately
