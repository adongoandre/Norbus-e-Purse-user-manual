Provident and Groupn Funds Module Overview

Welcome to Norbus e-Purse Fund Administration Module

The Fund Administration module is designed to manage provident fund operations, including scheme management, member administration, transaction processing, and NAV calculations. This comprehensive module handles all aspects of fund administration from setup to daily operations.

The Fund Administration module provides complete functionality for:

  • Master data setup and management
  • Scheme configuration and administration
  • NAV computation and fee management
  • Transaction processing and approvals
  • Gain distribution and reconciliation
  • Reversal management and authorizations
  • Comprehensive audit trails

Getting Started with Fund Administration
1 Master Setup: Configure administrators and fee structures before creating schemes.
2 Scheme Creation: Set up fund schemes with banks, member groups, and vesting rules.
3 NAV Management: Compute and approve NAV calculations regularly.
4 Transaction Processing: Handle member transactions through the approval workflow.
Best Practice: Always follow the maker-checker approval process for all transactions.

Master Setups

Core Configuration Management

Administrator Management allows you to create and manage system administrators who will oversee fund operations. Administrators have elevated privileges for system configuration and oversight.

Key Features:
  • New Administrator: Create new administrator accounts with specific roles and permissions
  • Search Administrator: Find and manage existing administrator accounts
  • Role Assignment: Assign specific administrative roles and access levels
  • Activity Monitoring: Track administrator activities and system access
Security Note: Administrator accounts should be created only for authorized personnel.

Fee Management enables you to configure various fee structures that will be applied to fund schemes. This includes management fees, performance fees, and transaction-based charges.

Fee Configuration Options:
  • New Fee: Create new fee structures with specific parameters
  • Search Fees: View and modify existing fee configurations
  • Fee Types: Configure different types of fees (management, performance, transaction)
  • Calculation Methods: Set up percentage-based or fixed fee calculations
Note: Fee structures must be configured before creating schemes that will use them.

Scheme Management

Fund Scheme Configuration

Scheme Setup is the core functionality for creating and managing fund schemes. Each scheme represents a distinct fund with its own investment strategy and member base.

Scheme Management Features:
  • New Scheme: Create new fund schemes with comprehensive configuration
  • Search Schemes: Find and manage existing schemes
  • Scheme Parameters: Configure investment objectives, risk profiles, and operational rules
  • Member Enrollment: Set up member registration and onboarding processes

Scheme Banks configuration allows you to assign banking relationships to specific schemes. This determines where scheme funds are held and processed.

Banking Configuration:
  • Bank Assignment: Link schemes to specific banking institutions
  • Account Setup: Configure bank accounts for scheme operations
  • Transaction Routing: Set up automatic routing of scheme transactions
  • Reconciliation Setup: Configure bank reconciliation parameters

Scheme Fee Configuration:

Link previously configured fee structures to specific schemes.

Scheme Member Groups:

Create member groups within schemes for differential treatment or reporting.

Scheme Upfront Charges:

Configure one-time charges applied at the time of member enrollment or investment.

Scheme Vesting Rules:

Set up vesting schedules that determine when members become entitled to employer contributions.

NAV Management

Net Asset Value Operations

Compute NAV functionality calculates the Net Asset Value for fund schemes. This is a critical daily operation that determines the value of member investments.

NAV Computation Features:
  • Automated Calculation: System calculates NAV based on portfolio valuations
  • Valuation Sources: Integration with market data providers for accurate pricing
  • Multi-Scheme Support: Compute NAV for multiple schemes simultaneously
  • Historical Tracking: Maintain complete NAV history for reporting and analysis
Best Practice: NAV should be computed daily after market close for accurate valuations.

Post NAV Fees applies the configured fee structures to schemes after NAV computation. This ensures accurate fee calculations based on current asset values.

Fee Posting Process:
  • Automatic Application: Fees are applied based on pre-configured rules
  • Fee Accrual: System handles daily accrual of management fees
  • Performance Fees: Calculate and apply performance-based fees when applicable
  • Fee Reconciliation: Ensure accuracy through automated reconciliation processes

Transactions

Member Transaction Processing

Purchase Transactions handle member contributions and investments into fund schemes. This includes both regular contributions and ad-hoc investments.

Purchase Processing:
  • Receipt Processing: Handle incoming member contributions
  • Unit Allocation: Calculate units based on current NAV
  • Contribution Types: Support for regular and voluntary contributions
  • Automatic Processing: Streamlined workflow for routine contributions

Transfer Applications facilitate the movement of member funds between different schemes or to external providers while maintaining compliance with regulations.

Transfer Features:
  • Inter-Scheme Transfers: Move funds between schemes within the system
  • External Transfers: Process transfers to external fund managers
  • Partial/Full Transfers: Support for both partial and complete fund transfers
  • Compliance Checks: Automated validation of transfer eligibility

Merge Applications:

Combine multiple member accounts or consolidate investments for administrative efficiency.

Transaction Uploads (Migration):

Bulk upload functionality for migrating historical transactions from legacy systems or processing large batches of transactions efficiently.

Migration Note: Use transaction uploads for one-time data migration or bulk processing scenarios.

Gain Distribution

Investment Gain Management

Distribute Gains manages the allocation of investment gains to member accounts based on their holdings and the scheme's distribution policy.

Distribution Features:
  • Automated Distribution: Calculate and distribute gains based on member holdings
  • Distribution Policies: Apply scheme-specific distribution rules and schedules
  • Pro-Rata Allocation: Ensure fair distribution based on member investment ratios
  • Tax Considerations: Handle tax implications of gain distributions

Gain Reconciliation ensures accuracy in gain calculations and distributions by comparing system calculations with external sources and identifying discrepancies.

Reconciliation Process:
  • Automated Matching: Compare internal calculations with external data sources
  • Discrepancy Reporting: Identify and report any calculation differences
  • Audit Trail: Maintain detailed records of all reconciliation activities
  • Correction Workflow: Process to handle and approve reconciliation adjustments

Authorizations

Approval Workflow Management

All submitted items requiring approval are managed through this comprehensive authorization system, ensuring proper oversight and compliance with organizational policies.

Approve or reject administrator and fee setup changes that have been submitted for review.

Review and approve scheme-related configurations including banks, member groups, and vesting rules.

Available Authorization Categories:
  • Transactions: Purchase, transfer, and merge applications
  • NAVs: Computed NAV calculations requiring approval
  • Distributed Gains: Gain distribution calculations and allocations
  • Withdrawals: Member withdrawal and termination requests
  • Transaction Uploads: Bulk transaction migration data

Reversals

Transaction Reversal Management

Handle the reversal of approved transactions when corrections or cancellations are required. All reversals follow a controlled approval process to maintain system integrity.

Available Reversal Types:
  • Reverse Purchase: Cancel purchase transactions and restore previous balances
  • Reverse Transfers: Undo transfer transactions between schemes or external parties
  • Reverse Merge: Separate previously merged accounts or investments
  • Reverse Withdrawal/Termination: Cancel withdrawal requests and restore member status
Important: All reversals require proper authorization and documentation.

Critical System Reversals:
  • Reverse NAV: Cancel NAV calculations when errors are detected
  • Reverse Distributed Gains: Undo gain distribution calculations and member allocations
Caution: NAV and gain distribution reversals affect multiple members and require senior approval.

Reversal Authorizations

Reversal Approval Management

All reversal requests must be approved through this authorization workflow to ensure proper oversight and prevent unauthorized system changes.

Transaction Reversal Approvals:
  • Purchases: Approve reversal of purchase transactions
  • Transfers: Authorize reversal of transfer operations
  • Merge: Approve account merge reversal requests
  • Withdrawals/Terminations: Authorize cancellation of withdrawal requests
System Operation Reversal Approvals:
  • NAV: Authorize reversal of NAV calculations
  • Distributed Gains: Approve reversal of gain distributions
Note: Reversal authorizations require detailed justification and senior management approval for system integrity.
