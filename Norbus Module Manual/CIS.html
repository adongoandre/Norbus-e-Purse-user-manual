Mutual Fund Module Overview

Welcome to Norbus e-Purse Mutual Fund Module

The Mutual Fund (MF) system is a comprehensive platform designed to manage collective investment schemes, fund operations, and investor services within the Norbus e-Purse ecosystem. This system provides end-to-end fund management capabilities from setup to daily operations.

The MF module handles all fund-related operations including:

  • Fund Setup and Configuration
  • Net Asset Value (NAV) Calculation
  • Purchase and Redemption Processing
  • Fund Distribution Management
  • Reconciliation and Reporting
  • Multi-level Authorization Workflow
  • Real-time Notifications and Alerts
Master Setups

Configure fund types, unit classes, and system parameters

CIS Products

Create and manage collective investment schemes

Umbrella Structure

Manage umbrella funds and sub-fund structures

NAV Processing

Calculate and manage net asset values

Transactions

Process transfers, switches, and mergers

Fund Distribution

Manage dividend and income distributions

System Access Requirements
1 Login Credentials: Ensure you have valid username and password provided by your system administrator.
2 Browser Requirements: Use a modern web browser (Chrome, Firefox, Safari, Edge) with JavaScript enabled.
3 Network Access: Ensure stable internet connection and access to the organization's network.
4 User Permissions: Your access level determines which features are available to you.
Security Note: Always log out when finished and never share your login credentials.

Master Setups

Fund Configuration

Set up and manage the foundational parameters for mutual funds including fund types, unit classes, and system-wide settings.

Fund types define the investment strategies and asset classes for mutual funds. You can create, edit, or delete fund types as needed.

Clicking on set up new fund type allows you to add a new fund type.

Unit classes define the different share classes available for funds, each with its own fee structure and investor eligibility.

Clicking on set up new unit class allows you to create a new unit class.

CIS Products

Collective Investment Schemes

Manage collective investment schemes (CIS) including fund setup, configuration, and product management.

CIS Configuration Components
  • Fund Basic Information and Objectives
  • Investment Strategy and Asset Allocation
  • Fee Structure and Load Configuration
  • Risk Profile and Investor Suitability
  • Regulatory Compliance Parameters
  • Distribution and Marketing Settings

Set up new collective investment schemes with detailed fund parameters, investment objectives, and compliance requirements.

Clicking on set up new CIS allows you to create a new collective investment scheme.

Utilize the search functionality to quickly find existing collective investment schemes based on various criteria such as fund type, unit class, and investment strategy.

Clicking on search CIS products opens the search interface.

Umbrella & Sub Structure

Umbrella Fund Architecture

Manage complex fund structures with umbrella funds containing multiple sub-funds, enabling efficient portfolio management and cost sharing.

Create new umbrella fund structures to group multiple sub-funds under a single umbrella, allowing for shared services and cost efficiencies.

Manage existing umbrella and sub-fund structures, including modifications to configurations, performance monitoring, and compliance checks.

Clicking on set up main fund allows you to setup a fund as a main fund.

Clicking on Edit allows you to edit an umbrella fund.

Clicking on constituent allows you to view and delete sub funds of a main fund.

Manage existing umbrella and sub-fund structures, modify configurations, and monitor performance across the entire fund family.

Internal Controls

Control Parameters

Establish and manage internal controls to ensure compliance limit and cut-off amounts for operational efficiency within mutual fund operations.

  • Maximum deposit amounts per transaction
  • Daily cut-off times for purchases and redemptions
  • Transaction limits

Configure maximum deposit limits and cut-off times for transactions to ensure compliance with fund policies.

Clicking on edit allows you to configure deposit limits.

NAV Operations

Net Asset Value Processing

Daily calculation and management of fund Net Asset Values, including fee processing and performance tracking.

Run daily NAV calculations for all funds, ensuring accurate pricing and performance tracking.

Clicking on run NAV allows you to initiate the NAV calculation process.

Process management and performance fees after NAV calculations, ensuring accurate fee deductions and investor account updates.

Clicking on post NAV fees allows you to process fees for the calculated NAV.

NAV Calculation Components
1 Asset Valuation
2 Liability Calculation
3 Unit Reconciliation
4 Fee Processing

Transactions

Investor Transactions

Manage investor transactions including purchases, redemptions, and transfers with comprehensive tracking and validation.

Process transfers of units between investor accounts with complete audit trails and validation checks.

Clicking on transfer allows you to initiate a transfer transaction.

Facilitate unit exchanges between different funds for investors, ensuring compliance with fund rules and validation checks.

Clicking on switch allows you to initiate a switch transaction.

Merge multiple investor accounts into a single account, ensuring all transactions are properly recorded and validated.

Clicking on merge allows you to initiate a merge transaction.

Reconciliation

Daily Reconciliation Processes

Ensure accuracy and completeness of all transactions through systematic reconciliation of purchases, receipts, and bank balances.

Reconcile purchase applications against received funds to ensure all transactions are accurately recorded.

Clicking on purchase reconciliation allows you to initiate the reconciliation process for purchases.

Verify that all investor payments have been received and reconciled against system records.

Clicking on receipt reconciliation allows you to initiate the reconciliation process for receipts.

Reconcile system records with bank statements to ensure all transactions are accurately reflected in financial records.

Clicking on bank reconciliation allows you to initiate the reconciliation process for bank transactions.

Daily Requirement: All reconciliations must be completed before end of business day to ensure accurate NAV calculations.

Fund Distribution

Dividend and Income Distribution

Process fund distributions to investors including dividends, capital gains, and other income allocations according to fund policies.

Process regular income distributions to investors based on fund performance and policies.

Clicking on distribute dividends allows you to initiate the dividend distribution process.

Troubleshooting

Common Issues and Solutions

Issue: NAV run fails or produces incorrect values

Solutions:

  1. Verify all asset valuations have been entered
  2. Check fund parameters and expense accruals
  3. Review error log for specific calculation issues
  4. Confirm unit/share balances are current

Issue: Unable to authorize transactions

Solutions:

  1. Verify you have proper authorization privileges
  2. Check for pending system notifications
  3. Confirm transaction details are complete
  4. Contact system administrator if issue persists

Issue: Reconciliation mismatches or failures

Solutions:

  1. Verify all transactions have been processed
  2. Check for unposted receipts or payments
  3. Review cutoff times for transaction inclusion
  4. Confirm bank statement dates match system period
